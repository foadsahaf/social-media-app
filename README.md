# 💬 Python Social Media Project

A simple console-based social media project built with **Python** and **SQL Server**.

## ✨ Features
- 👤 User Registration
- 🔐 User Login
- 📝 Create Posts
- ❤️ Like Posts
- 🗄️ SQL Server Database Integration

## 🛠️ Technologies
- Python 3.12
- Microsoft SQL Server
- PyODBC

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/python-sql-social-media.git
   ```
2. Install the required packages:
   ```bash
   pip install pyodbc
   ```
3. Configure your SQL Server connection.
4. Run the main Python file.

## 🎯 Purpose

This project was created as a practical exercise to learn Python database connectivity and implement basic social media functionalities.
